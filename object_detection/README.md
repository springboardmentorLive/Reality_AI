# OBJECT DETECTION

## Overview

This application is an object detection application that uses PyTorch and OpenCV to detect objects in an image.

## Table of Contents

- [Overview](#overview)
- [Applications](#applications)
- [Installation](#installation)

## Applications

- ```app.py```: Contains a class which creates an object detection application in CLI
- ```requirements.txt```: Contains the list of dependencies required for the application

## Installation

* Install the libraries from requirements.txt

- ```pip install -r requirements.txt```

* Run the object detection application

- ```python app.py```
