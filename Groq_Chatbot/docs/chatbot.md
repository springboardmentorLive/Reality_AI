# Simple AI Chatbot (`chatbot.py`)

## Overview
`chatbot.py` is a command-line interface (CLI) chatbot powered by Groq's Llama 3 model.

## Features
- **Interactive Chat**: A simple REPL (Read-Eval-Print Loop) where users can type messages and get responses.
- **Llama 3 Integration**: Uses the `llama-3.3-70b-versatile` model.

## Dependencies
- `groq`

## Usage
Run the script:
```bash
python chatbot.py
```
Type your message when prompted. Type `quit` to exit.
