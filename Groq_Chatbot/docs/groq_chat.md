# Poetry Generator (`groq_chat.py`)

## Overview
`groq_chat.py` is a specialized CLI chatbot designed to generate poetry based on user-provided themes and styles.

## Features
- **Poetry Generation**: Accepts a "Theme" and a "Style" from the user.
- **System Prompt**: instructing the AI to reply *only* in poetry.

## Dependencies
- `groq`

## Usage
Run the script:
```bash
python groq_chat.py
```
Follow the prompts to enter a theme and a style. Type `quit` to exit.
