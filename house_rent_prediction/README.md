# 🏠 House Rent Prediction

A Machine Learning web application that predicts monthly house rent based on:
- Location
- House size (sq ft)
- BHK
- Furnishing type

## 🔧 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn (Linear Regression)
- Streamlit

## ⚙️ How It Works
1. User selects house details
2. ML model predicts estimated rent
3. Result is displayed instantly

## ▶️ Run the Project
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
