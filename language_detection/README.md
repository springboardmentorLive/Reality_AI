# LANGUAGE DETECTION

## Overview

This application is a language detection application that uses Groq's LLM to detect the language of a given text.

## Table of Contents

- [Overview](#overview)
- [Applications](#applications)
- [Installation](#installation)

## Applications

- ```language_detection.py```: Contains a class which creates a language detection application in CLI
- ```audio.py```: Contains necessary libraries for audio processing
- ```requirements.txt```: Contains the list of dependencies required for the application

## Installation

* Install the libraries from requirements.txt

- ```pip install -r requirements.txt```

* Run the language detection application

- ```python language_detection.py```
