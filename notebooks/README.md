# Exploratory & Development Notebooks

This directory contains the original development, milestone, and exploratory Google Colab notebooks from earlier project phases:

- `day_1to5.ipynb`: Initial exploratory data analysis, data ingestion, and baseline modeling (Days 1–5).
- `day_6to10.ipynb`: Feature engineering, model experimentation, and baseline evaluations (Days 6–10).
- `bot.ipynb`: Early assistant / conversational interface prototyping.
- `meeting_summarizer.ipynb`: Meeting and transcript summarization exploration.
- `audio_detect.ipynb`: Audio analysis and voice event detection experiments.

The production multimodal architecture, training pipelines, and interactive application reside in `pipelines/`, `models/`, and `app/`.
