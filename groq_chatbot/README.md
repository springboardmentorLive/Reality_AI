# GROQ CHATBOT

## Overview

This application is a chatbot that uses Groq's LLM to generate responses to user queries. It also has a poem generator that uses Groq's LLM to generate poems based on user input.

## Table of Contents

- [Overview](#overview)
- [Applications](#applications)
- [Installation](#installation)

## Applications

- ```app.py```: Contains a class which creates a web application using Streamlit
- ```groq_chatbot.py```: Contains a class which creates a chatbot in CLI
- ```poem_generator.py```: Contains a class which creates a poem generator in CLI
- ```requirements.txt```: Contains the list of dependencies required for the application

## Installation

* Install the libraries from requirements.txt

- ```pip install -r requirements.txt```

* Run the streamlit file

- ```streamlit run app.py```
