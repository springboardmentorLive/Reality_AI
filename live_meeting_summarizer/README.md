# LIVE MEETING SUMMARIZER

## Overview

This application is a live meeting summarizer that uses Groq's LLM to summarize the live meeting.

## Table of Contents

- [Overview](#overview)
- [Applications](#applications)
- [Installation](#installation)

## Applications

- ```app.py```: Contains a class which creates a live meeting summarizer application in CLI
- ```requirements.txt```: Contains the list of dependencies required for the application

## Installation

* Install the libraries from requirements.txt

- ```pip install -r requirements.txt```

* Run the live meeting summarizer application

- ```python live_meeting_summarizer.py```
